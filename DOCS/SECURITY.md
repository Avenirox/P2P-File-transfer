# EN
## Security Policy

### Reporting a Vulnerability
As a peer-to-peer file transfer application, security is extremely important to us. If you discover any security vulnerability, please **do not** open a public issue. 

Instead, report it privately by contacting us via email: **avenirox.support@gmail.com**.

We will investigate the issue and release a fix as soon as possible. Thank you for helping keep our users safe!

# PL
## Polityka bezpieczeństwa

### Zgłaszanie problemów z bezpieczeństwem
Jest to program peer-to-peer więc zależy nam na bezpieczenstwie. Jeśli znajdziesz jakiś problem z bezpieczeństwem **nie otwieraj** issue na GitHub.

Zamiast tego skontaktuj się z nami przez poczte email: **avenirox.support@gmail.com**

Postaramy się naprawić problem jak najszybciej. Dziekujemy za wsparcie i rozwój!
