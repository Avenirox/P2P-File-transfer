# EN
## Contributing to P2P File Sender

Thank you for your interest in improving our project! We welcome all contributions.

### How to Contribute
1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally and create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/my-awesome-feature
   ```
3. **Commit** your changes with clear messages.
4. **Push** your branch to GitHub and open a **Pull Request** against our `main` branch.

### Guidelines
- Make sure the application launches locally without errors before submitting.
- Keep your code clean and format it properly.

**When we have a time, we review it.**

Dziękujemy za zainteresowanie i pomoc w rozwoju! Nie tylko my go rozwijamy ale równierz wy!

### Jak zrobić pull request
1. **Zforkuj** repozytorium do swojego konta GitHub.
2. **Zclonuj** swojego forka lokalnie i stwórz nowego brancha z nową funkcją lub naprawionym bugiem:
   ```bash
   git checkout -b feature/moja-swietna-funkcja
   ```
3. **Zcommituj** swoje zmiany z wiadomoscią.
4. **Zpushuj** brancha do GitHuba i otwórz **Pull Request** do `main` brancha
